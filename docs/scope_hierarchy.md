# Scope hierarchy

## Must have

cpgLib builds reproducibly.
A small test harness demonstrates and records CPG triggers.
A standalone JUCE application uses the engine.
Users can create or manipulate a small CPG network.
The application outputs useful MIDI.
A network/preset can be saved and restored.
The app runs on the selected tablet.
A pilot study is completed.
The final study and report are completed.

## Should have

tempo controls;
clear visual feedback for node activity;
stable layout and touch targets;
a small preset library;
basic performance logging;
multiple MIDI mappings;
device/DAW workflow documentation.
minimal VST3 or AU plugin;

## Could have

host tempo synchronization;
rhythm morphing;
advanced gesture vocabulary;
MIDI clock, Ableton Link or OSC;
internal sounds;
extensive animation.
